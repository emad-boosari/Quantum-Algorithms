## About This Repository

This repository contains notebooks and examples related to Grover's Search Algorithm and its applications.

Topics covered include:

* The fundamentals of Grover's Search Algorithm
* Oracle construction and phase marking
* The diffusion (amplitude amplification) operator
* Multi-solution search problems
* General Amplitude Amplification techniques
* Quantum counting
* Optimization problems solved using Grover-based search
* Practical implementations using Qiskit

The material is designed to progress from introductory concepts to more advanced applications, providing both theoretical explanations and hands-on coding examples.
